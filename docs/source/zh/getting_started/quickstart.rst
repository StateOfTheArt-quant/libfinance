========
快速开始
========

五分钟走通一条完整链路：\ **先确定交易日 → 再确定标的 → 再取行情**\ 。

这个顺序不是随便排的。交易日历和证券主数据是所有查询的参照系：日期要落在交易日上，
代码要能被解析成一只真实的证券，否则后面那一步的结果会莫名其妙地空掉。

..  note::

    下面所有输出都是真实运行结果。日期和数值取决于你连的服务更新到哪天，
    **不要照抄日期**\ 。

第一步：交易日
==============

..  code-block:: python

    >>> from libfinance import get_trading_dates
    >>> get_trading_dates("2024-05-11", "2024-05-20")
    DatetimeIndex(['2024-05-13', '2024-05-14', '2024-05-15', '2024-05-16',
                   '2024-05-17', '2024-05-20'],
                  dtype='datetime64[ns]', freq=None)

注意 5 月 11、12 日（周六周日）和 5 月 18、19 日不在里面。区间两端按自然日给，返回的
只有交易日。

第二步：标的
============

代码写成 ``<交易所代码>.<市场后缀>``\ ：上交所 ``.XSHG``\ 、深交所 ``.XSHE``\ 、美股 ``.US``\ 。

..  code-block:: python

    >>> from libfinance import instruments
    >>> instruments("600000.XSHG")
    Instrument(order_book_id='600000.XSHG', symbol='浦发银行', type='CS',
               market='cn', listed_date='1999-11-10T00:00:00.000')

``order_book_id`` 是代码，\ ``symbol`` 是\ **名称**——这两个词的含义容易记反。

第三步：行情
============

..  code-block:: python

    >>> from libfinance import get_price
    >>> get_price(["000001.XSHE", "600000.XSHG"], "2024-03-01", "2024-03-06")

..  code-block:: text

返回值是一个 ``DataFrame``\ ，索引是 ``(order_book_id, datetime)`` 两层。取单只票用
``df.loc["000001.XSHE"]``\ ，取某一天用 ``df.xs("2024-03-04", level="datetime")``\ 。

..  important::

    上面 ``000001.XSHE`` 在 2024-03-01 的收盘价是 **8.81**\ ，但那天的实际成交价是
    **10.49**\ 。因为默认 ``adjust_type="pre"``\ （前复权）。

    要历史上真实的成交价，显式写 ``adjust_type="none"``\ 。这件事很重要，
    :doc:`../data/price` 整章都在讲它。
