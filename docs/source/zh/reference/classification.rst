4 行业和概念信息
========================================

.. list-table::
    :header-rows: 1

    * - 函数 / 类

    * - :func:`~libfinance.get_concept_meta`
      - 发现可查询的概念名称和编号
    * - :func:`~libfinance.get_concept_weights`
      - 查询一个或多个概念在指定知识时点的成分权重
