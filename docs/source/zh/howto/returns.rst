==========
计算收益率
==========

**目标**\ ：从行情算出日收益率，并且不被除权事件污染。

结论先说：\ **算收益率必须用复权价**\ 。用未复权价的话，每一个分红送转日都会变成一次
虚假的下跌。

一个具体例子
============

``600000.XSHG`` 在 2024-07-18 除权，每股派现 0.321 元。把两种口径放在一起：

..  code-block:: python

    import pandas as pd
    from libfinance import get_price

    raw = get_price(["600000.XSHG"], "2024-07-15", "2024-07-22",
                    adjust_type="none")["close"].droplevel(0)
    adj = get_price(["600000.XSHG"], "2024-07-15", "2024-07-22")["close"].droplevel(0)

    out = pd.DataFrame({"未复权": raw, "前复权": adj})
    out["未复权收益率"] = out["未复权"].pct_change()
    out["前复权收益率"] = out["前复权"].pct_change()

..  code-block:: text

                 未复权       前复权    未复权收益率    前复权收益率
    datetime
    2024-07-15  8.88  7.937594       NaN       NaN
    2024-07-16  8.86  7.919716 -0.002252 -0.002252
    2024-07-17  9.04  8.080613  0.020316  0.020316
    2024-07-18  8.77  8.127879 -0.029867  0.005849     <- 除权日
    2024-07-19  8.73  8.090808 -0.004561 -0.004561
    2024-07-22  8.58  7.951791 -0.017182 -0.017182

看 2024-07-18 那一行：未复权算出来是 **跌 2.99%**\ ，复权后是 **涨 0.58%**\ 。

真实情况是涨的。那 2.99% 的"跌幅"里，绝大部分是每股派出去的 0.321 元——钱从股价里
挪到了股东口袋里，不是亏损。

其余每一天两者\ **完全相同**——复权只在有事件的那天改变收益率，平时不动。

多只股票
========

行情返回的是两层索引，\ ``unstack`` 成宽表后就能直接算：

..  code-block:: python

    from libfinance import get_price

    close = get_price(["000001.XSHE", "600000.XSHG"],
                      "2024-03-01", "2024-03-08")["close"]
    wide = close.unstack("order_book_id")
    returns = wide.pct_change()

几个容易出错的地方
==================

..  list-table::
    :header-rows: 1
    :widths: 34 66

    *   - 做法
        - 说明
    *   - 用 ``close * volume`` 当成交额
        - **不要**\ 。直接用 ``turnover`` 列。复权口径下 ``close`` 和 ``volume``
          都被缩放过，虽然乘积守恒，但不如直接取现成的列
    *   - 跨很长区间用前复权
        - 前复权以最近价格为基准，\ **加入新的除权事件会让整条历史序列变化**\ 。
          需要一条不随时间变化的净值曲线时用 ``adjust_type="post"``
    *   - 停牌日
        - 默认保留（成交量为 0），收益率会算出 0。要剔除就传 ``skip_suspended=True``
    *   - 第一行是 ``NaN``
        - ``pct_change()`` 的正常行为，用 ``.dropna()`` 去掉

后复权注意
==========

后复权需要从最早的基准日累乘因子。个别股票早期有无法定价的公司行动，这时服务端会
**拒绝**\ 而不是给一个偏掉的结果，报错里会写明从哪一天起是安全的：

..  code-block:: python

    >>> get_price(["000001.XSHE"], "2024-03-01", "2024-03-06", adjust_type="post")
    RpcError: ... has 11 corporate action(s) with no factor in this release ...;
    Ask from base_date=1999-10-18 onward, ...

按它给的日期重新取即可。
